# 住宅 IP 串联：让指定网站看到固定的住宅 IP

自建节点的出口是云服务器的**数据中心 IP**。有些网站（部分 AI 服务、支付、流媒体等）对数据中心 IP 风控很严：频繁弹验证码、提示「异常活动」、无法登录或付款。

解决办法是在自己的节点后面再串一个**静态住宅 IP**，只让这些网站从住宅 IP 出去，其他流量照旧：

```
你的电脑/手机 ──(Hysteria2 / Reality，负责穿墙)──▶ 你的服务器 ──(SOCKS5)──▶ 静态住宅 IP ──▶ 目标网站
                                                         │
                                                         └──(直连)──▶ 其他所有网站
```

- **穿墙**仍然靠你自己的节点（住宅代理是普通 SOCKS5，没有任何伪装，在国内直接用会被识别）。
- **目标网站**看到的是住宅 IP，而且一直是同一个。

## 前提
- 已经按 [proxy-node-manual](https://github.com/RestezCalme/proxy-node-manual) 部署好节点（Xray Reality + Hysteria2），客户端能正常使用。
- 买好一个**静态住宅** SOCKS5 代理（以 Webshare 为例），见《[购买与注意事项](购买与注意事项.md)》。

## 两种方案，选一个

| | [方案 A：客户端串联](方案A-客户端串联.md) | [方案 B：服务端串联](方案B-服务端串联.md) |
|---|---|---|
| 改哪里 | 只改自己电脑的 Clash 配置 | 改服务器上 Xray 和 Hysteria2 的配置 |
| 影响范围 | 只有配置了的这台设备 | 所有连这台服务器的设备和用户（手机不用改） |
| 适合 | 只有自己一台电脑需要 | 多台设备或多人共用；手机客户端不方便配置串联 |
| 出问题时 | 只影响本机，删掉三段配置即可恢复 | 整台节点受影响，需要按说明回滚 |
| 难度 | ⭐ | ⭐⭐ |

**不确定就选方案 A**：改动小、风险只在本机，随时可以撤掉。
